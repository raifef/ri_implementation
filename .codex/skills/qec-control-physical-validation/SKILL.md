# QEC Control Physical Validation

Read `../../../skill/qec-control-physical-validation/SKILL.md` completely before
implementing, modifying, reviewing, or benchmarking a simulated QEC calibration or
control system in this repository. That workspace-maintained document is the complete
skill specification and is authoritative for the validation ladder, sample-budget
checks, evidence boundaries, preflight requirements, and definition of done.

Use it together with `.codex/skills/hdfa-rl-suite/SKILL.md` and the revision-2 Word
architecture documents. A passing procedural benchmark is never a substitute for a
physically validated plant and independently functioning reference controller.
